# Official HL7 example documents (CC0)

Unmodified example files used by `hl7-examples.test.ts` to test the parsers on real-world
document structure. They are examples written by HL7, not patient data, and are never used to
judge model accuracy.

| File | Source | Licence |
|---|---|---|
| `ccda-ccd-1.xml`, `ccda-ccd-2.xml`, `ccda-discharge-summary.xml` | HL7 C-CDA Examples, `Documents/CCD/CCD 1`, `CCD 2`, `Discharge Summary` (<https://github.com/HL7/C-CDA-Examples>) | CC0 1.0 |
| `fhir-r4-patient-example.{xml,json}`, `fhir-r4-document-example-dischargesummary.{xml,json}` | FHIR R4 specification examples (<https://hl7.org/fhir/R4/>) | CC0 1.0 |
